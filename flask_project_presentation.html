🏗️ MVC Architecture Pattern

  • Model (M) - app/models.py - Data layer and business logic
  • View (V) - app/templates/ - Presentation layer (HTML templates)
  • Controller (C) - app/user/controller.py - Request handling and routing
  • Separation of Concerns - Each layer has distinct responsibilities
  • Maintainability - Changes in one layer don't affect others
  • Testability - Each component can be tested independently

@user_bp.route('/login', methods=['GET', 'POST'])
def login():
    form = LoginForm(request.form)
    if request.method == 'POST' and form.validate():
        # Get data from Model
        user = models.Users.get_by_username(form.username.data)
        if user and user.check_password(form.password.data):
            login_user(user)
            # Redirect to View
            return redirect(url_for('user.index'))
    # Render View with data
    return render_template('login.html', form=form)

Blueprint Architecture

🧩 What are Blueprints?

  • Modular Organization - Group related functionality together
  • Scalability - Add new features without modifying core app
  • Team Development - Different developers can work on different blueprints
  • Reusability - Blueprints can be shared across projects
  • URL Prefixes - Organize routes with prefixes like /user/
  • Template Folders - Each blueprint can have its own templates

📁 Blueprint Structure


app/user/                   # User blueprint directory
├── __init__.py            # Blueprint creation and registration
├── controller.py          # Route handlers (views)
└── forms.py              # WTForms for this blueprint

# Each blueprint is self-contained:
# - Routes for specific functionality
# - Forms related to that feature
# - Can have its own templates
# - Can have its own static files

🔄 Request Flow in Our Architecture

  1. 1. Request - User accesses /user/register
  2. 2. Blueprint Routing - Flask finds user_bp.route('/user/register')
  3. 3. Controller - register() function handles the request
  4. 4. Model - Controller calls Users.add() if needed
  5. 5. View - Controller renders signup.html template
  6. 6. Response - HTML sent back to user's browser

Database Schema

CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,

Database Layer

Connection Management


# database.py - Connection management
def get_db_connection():
    if not hasattr(g, 'db_conn'):
        g.db_conn = psycopg2.connect(
            host=os.getenv('DB_HOST', 'localhost'),
            port=os.getenv('DB_PORT', '5432'),
            database=os.getenv('DB_NAME'),
            user=os.getenv('DB_USERNAME'),
            password=os.getenv('DB_PASSWORD')
        )
    return g.db_conn

@app.teardown_appcontext
def close_db_connection(error):
    db = g.pop('db_conn', None)
    if db is not None:
        db.close()

Model Implementation


# models.py - Users class
class Users:
    def add(self, username, email, password):
        conn = get_db_connection()
        cursor = conn.cursor()

        # Hash password (MD5 for demo)
        hashed_password = hashlib.md5(password.encode()).hexdigest()

        cursor.execute("""
            INSERT INTO users (username, email, user_password)
            VALUES (%s, %s, %s)
        """, (username, email, hashed_password))

        conn.commit()
        cursor.close()

Authentication System

Flask-Login Integration


# User loader callback
@login_manager.user_loader
def load_user(user_id):
    return Users.get_by_id(user_id)

# Login route
@app.route('/login', methods=['GET', 'POST'])
def login():
    form = LoginForm()
    if form.validate_on_submit():
        user = Users.authenticate(
            form.username.data,
            form.password.data
        )
        if user:
            login_user(user, remember=form.remember_me.data)
            return redirect(url_for('user.index'))
        flash('Invalid credentials')
    return render_template('login.html', form=form)

Form Handling

WTForms Implementation


# user/forms.py
from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, BooleanField
from wtforms.validators import DataRequired, Email

class UserForm(FlaskForm):
    username = StringField('Username', validators=[DataRequired()])
    email = StringField('Email', validators=[DataRequired(), Email()])
    password = PasswordField('Password', validators=[DataRequired()])

class LoginForm(FlaskForm):
    username = StringField('Username', validators=[DataRequired()])
    password = PasswordField('Password', validators=[DataRequired()])
    remember_me = BooleanField('Remember Me')
